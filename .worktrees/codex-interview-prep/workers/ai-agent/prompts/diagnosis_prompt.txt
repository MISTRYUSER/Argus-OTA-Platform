## 诊断结果
请严格按照以下 JSON 格式输出（不要包含 Markdown 代码块标记）：

```json
{
  "root_cause": "根本原因描述（简洁明确，不超过50字）",
  "suggestions": [
    "建议1（具体操作步骤）",
    "建议2（验证方法）",
    "建议3（预防措施）"
  ],
  "severity": "high/medium/low",
  "confidence": 0.85
}
```

### 字段说明
- **root_cause**: 根本原因，简洁描述导致故障的核心问题
- **suggestions**: 3-5条建议，按优先级排序，每条建议要具体可操作
- **severity**: 严重程度
  - `high`: 影响驾驶安全，需要立即处理
  - `medium`: 影响功能但不影响安全，需要尽快处理
  - `low`: 轻微问题，可以延后处理
- **confidence**: 置信度 (0.0-1.0)
  - `>= 0.8`: 数据充分，结论可靠
  - `0.5-0.8`: 数据基本充分，结论基本可靠
  - `< 0.5`: 数据不足，结论仅供参考
