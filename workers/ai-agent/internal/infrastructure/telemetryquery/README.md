# Scoped telemetry evidence

Trusted immutable batch bindings determine namespace, service, and the incident window (at most one hour). Model arguments only select an allowlisted metric, literal log substring, trace status, and result limit. No arbitrary query language, endpoint, or scope override is accepted.

Backend reads are limited to 1 MiB. The returned evidence array is separately limited to **16 KiB of serialized JSON per query**, including JSON escaping and provenance, and each Content string is at most **1000 Unicode code points**. A query can request up to 100 records; a smaller prefix may fit the output budget. The final returned item marks `result_truncated=true returned=N available=M` when normalized records were omitted by the byte budget. Long Content is a text preview, with an explicit `[truncated original_sha256=...]` suffix; it should not be parsed as complete JSON. Source records `content_truncated=true`. Backend result limits may independently mean further matches are not retrieved.

Every Source contains `original_sha256`, computed over the canonical JSON of the original scoped record before display normalization. Evidence IDs also incorporate that original record, its query and trusted provenance; two records whose visible previews match but whose omitted tails differ have different IDs. Metric previews contain only the allowlisted metric, trusted namespace/service, timestamp and a validated numeric string (at most 64 bytes), rather than arbitrary backend labels. Loki previews similarly exclude extra stream labels. Trace previews contain selected matched span metadata, never unrelated trace-root metadata.

Prometheus request bounds retain fractional seconds and round inward to backend millisecond precision (start upward, end downward). Windows with no representable in-scope millisecond return an explicit empty evidence array without a backend request. Sample bounds are compared as exact rational timestamps, so samples one nanosecond outside the binding are rejected. Tempo 2.9 may return selected resource attributes using `k8s.namespace.name` and `service.name`; qualified `resource.` names are also accepted. Conflicting aliases or conflicting duplicate values fail closed.

The normalization budget reserves room for the Agent's copies of evidence in observations, conversations, and completed results. It is not a whole-checkpoint size guarantee: local log inputs and other tools also consume space. Checkpoint bounds must be enforced and verified by the consuming Agent.
